# Roadmap

排序原则：先补齐"每天都在用"的确定性体验，再考虑扩展。

## Now（0.1.x，已完成）

- 多源聚合与逐源开关
- 中英/拼音即时搜索
- 下载 → 解压 → 归档 → manifest
- 本地库管理与版本比对
- 明暗主题、中英界面
- Windows 单文件打包 + CI 自动发布

## Next（0.2，体验闭环）

| 事项 | 判断标准 | 说明 |
| --- | --- | --- |
| 首屏版本预热 | 打开即有版本号的比例 ≥ 80% | 对可视区前 N 条做低优先级详情预取 |
| 按游戏的「已安装 / 可更新」面板 | 库内条目可一眼看出状态 | 现在只能看到总数 |
| 便携模式 | `TrainerHub.portable` 时配置落在 exe 同目录 | U 盘场景 |
| 下载队列持久化 | 重启后可恢复未完成任务 | 断点续传已有，缺队列状态 |

## Later（0.3，扩展边界）

| 事项 | 前提 |
| --- | --- |
| Cheat Engine `.CT` 源 | 需要专用查看器，且分发协议与 exe 不同 |
| 社区投稿 + 审核队列 | 需要服务端、存储与审核人力，属于另一个产品问题 |
| AI 辅助（自然语言找修改器 / 失败诊断） | 先证明基础链路稳定；AI 层必须可降级为规则，否则会掩盖解析问题 |

## Won't do

- 在线游戏作弊、反作弊绕过
- 托管、镜像、再分发第三方修改器文件
- 未经审核的分发渠道
