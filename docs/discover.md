# TrainerHub v0.3.0：发现

## 用户操作

- 首次只显示一句标题与“扫描 Steam”按钮。扫描本地已安装游戏后生成推荐，不自动下载或运行文件。
- 列表只显示游戏名、来源和必要状态。高、中置信推荐都能直接选择下载；推荐依据放在按需展开的详情，不增加中置信确认门槛。
- “重新扫描”刷新清单，“管理游戏”查看、排除或恢复游戏。没有可靠匹配的游戏可从管理页主动搜索。
- 下载所选提交到现有下载中心，失败和完成状态返回计划。已有修改器不默认重复下载；小幸备选只打开原站，不批量弹出浏览器。
- 输入搜索词切换到本地＋真实 FLiNG 搜索；清空恢复计划和选择。联网失败提供重试，不把网络失败当作没有 FLiNG。
- 同游戏已有 FLiNG 时隐藏小幸，来源筛选不能重新把小幸显示出来。不同续作、版本、DLC 不合并。

## 模块边界

| 模块 | 职责 |
| --- | --- |
| `core/steam_scan.py` | 定位 Steam 根目录，受限解析 VDF/ACF，多库只读扫描和安装状态判断 |
| `core/game_matching.py` | 预计算可靠名称与别名，分级匹配，保护数字、续作、版本及子标题 |
| `core/source_policy.py` | 游戏级来源裁决，先 FLiNG 优先，再按来源筛选 |
| `core/recommendation.py` | 从本地快照和目录生成内存计划，保留选择及执行状态 |
| `core/db.py` | 事务存储 Steam 快照和排除偏好，失败库保留旧快照 |
| `workers/discovery_worker.py` | 后台扫描及生成，协作取消，不直接提交扫描快照 |
| `ui/discovery_controller.py` | 校验代次后提交快照，管理选择、排除、清除和下载状态 |
| `workers/search_worker.py` | 有限查询变体、超时、查询代次及来源上下文，过期结果丢弃 |
| `core/remote_search.py` | 真实 FLiNG REST 请求、文章与链接校验、响应错误分类 |

依赖仍为 `ui → workers → core`。没有新增云服务、LLM 或其他游戏平台扫描器。

## 本地存储与边界

`SteamGame` 与已归档修改器 `InstalledItem` 独立。新增 `steam_games`、`steam_preferences` 表，扫描元信息位于 `meta` 的 `discovery.*` 项，不改变旧目录及库的主键。

只读取 `steamapps/libraryfolders.vdf` 与 `appmanifest_*.acf`。游戏安装目录仅检查存在性和路径边界，不遍历二进制、存档或账号文件。限制文件大小、嵌套深度及 token 数；单个损坏清单不阻塞其他游戏。

不可访问的库保留上次成功快照。取消扫描不提交半成品；清除与停用先使旧代次失效，避免旧回包重新写入。清除发现结果不删除 Steam 文件或已下载修改器。

设置位于“本地游戏发现”：启停、启动复扫、手动路径及清除。首次不自动扫描，启动复扫默认关闭。扫描及计划生成不批量上传游戏名；用户主动联网搜索会向 FLiNG 发送查询词。查询词不写入新增应用日志。

## 匹配与推荐

精确名称或可靠别名为高置信；受控变体与无歧义高相似候选为中置信，初始相似度阈值 90、不同游戏候选领先值 8。低置信或歧义不自动推荐，仍可搜索。

置信度是规则等级，不是统计概率，也不等于版本兼容性。不能从 Steam buildid 推导修改器兼容版本。罗马数字仅在明确续作位置转换，版本及 DLC 标记不全局删除。

计划不持久化批量任务编排；启动时从本地快照重新生成。用户主动下载后才进入原下载、解压与归档链路，任何下载物均不自动运行。

## 验证方式

本地完整回归：`QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest`；静态检查：`.venv/bin/ruff check src tests`。

真实桌面联网验收：`QT_QPA_PLATFORM=offscreen TRAINERHUB_LIVE_SEARCH_TEST=1 .venv/bin/python -m pytest tests/test_live_search.py -v`。默认回归不依赖外站；此项必须单独启用，不能用 Mock 通过替代。

真实测试从桌面搜索 Hades、Cyberpunk 2077，要求 FLiNG 结果替换同名小幸、详情可见、真实详情及下载地址解析成功。不下载或运行可执行文件。

GitHub `build-windows` 对 `v0.3.0` 和 `main` 执行静态检查、Qt 回归、真实联网验收、PyInstaller 打包以及 exe 启停冒烟。分支构建不会自动创建 Release；发布仍需单独的 tag 操作。

## 本轮证据与限制

2026-11-25，macOS、Python 3.12.14：真实桌面联网两例通过。源站详情返回 Hades 15 项、Cyberpunk 2077 46 项，下载目标均解析为直链。这只验证搜索、详情和解析，不冒充已执行下载安装或游戏内兼容性测试。

800 份隔离清单及 800 条精确目录：首遍扫描 227.13ms，重复扫描 131.30ms，本地计划 21.64ms。测试只检查一个共用的模拟安装目录；不是完整真实游戏库、低速外置磁盘或所有模糊匹配场景的性能承诺。

Windows 实体 Steam 库、实际游戏版本兼容性与第三方下载物的安全性未做人工实机验证。外站未来可用性不能永久保证；错误、重试与本地降级仍必须保留。
